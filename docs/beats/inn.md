# Inn palette

Copy into a story beat. Every alternative must fit the same frame.

```
{walked|came|limped} to the inn
sat by the {fire|window|door}
{ordered|asked for} {ale|stew|bread}
brought {a cup|a bowl|a plate}
{said|muttered|whispered}
the {knight|ranger|traveler}
the {liar|thief|priest}
the {innkeeper|boy}
```

Do not use `<place>`, `<noun-liquid>`, or `<noun-container>` here unless the host loaded a scene overlay that actually defines those names.
